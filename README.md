## 📚 Tentang Proyek

**Wandering Witch Translator** adalah aplikasi web sederhana untuk menerjemahkan teks **Latin** ke **Alfabet Majo Formal** (Wandering Witch) dan sebaliknya. Dilengkapi dengan virtual keyboard khusus untuk mengetik aksara Majo dengan mudah.

---

## ✨ Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 🔄 **Dua Mode** | Latin → Majo & Majo → Latin |
| ⌨️ **Virtual Keyboard** | Keyboard khusus aksara Majo untuk mode M→L |
| 📋 **Copy Output** | Salin hasil terjemahan ke clipboard |
| 🖌️ **Custom Font** | Menggunakan font asli Wandering Witch Formal |
| 🎨 **Desain Elegan** | Tema earthy dengan efek shadow yang halus |

---

## 🎮 Cara Penggunaan

### Mode Latin → Majo
1. Klik tombol **"Latin → Majo"**
2. Ketik teks Latin di area input
3. Hasil terjemahan langsung muncul dalam aksara Majo

### Mode Majo → Latin
1. Klik tombol **"Majo → Latin"**
2. Gunakan **virtual keyboard** yang muncul di bawah
3. Klik tombol aksara Majo untuk mengetik
4. Hasil Latin akan muncul di area output

### Fungsi Lain
- **Hapus Semua** — Membersihkan input & output
- **Salin** — Menyalin hasil terjemahan ke clipboard

## 📥 Instalasi & Penggunaan

### 1. Download Font
Pastikan file font `WanderingWitchFormal-Regular.otf` berada di **folder yang sama** dengan `index.html`.

### 2. Buka Halaman
```bash
# Cukup double-click file index.html
# Atau gunakan live server
npx live-server .
```

3. Mulai Menerjemahkan

Pilih mode yang diinginkan dan mulai ketik!

⚠️ Catatan Penting

Font Wajib Tersedia!
Proyek ini membutuhkan file WanderingWitchFormal-Regular.otf untuk menampilkan aksara Majo dengan benar. Tanpa font tersebut, tampilan akan fallback ke font biasa.
